Сначала принять изменения галереи из этого PR. Из папки _cabinet выполнить npx wrangler secret put ADMIN_PASSWORD (случайный длинный ASCII пароль), затем npx wrangler secret put GITHUB_TOKEN (fine-grained token только для этого репозитория, Contents: write), затем npx wrangler deploy. Передать Ольге адрес HTTPS приложения и логин olga. На iPhone: Safari → Поделиться → На экран Домой. Для загрузки подходит фото с согласием на публикацию: после отправки оба снимка публично сохраняются в одной записи репозитория.
