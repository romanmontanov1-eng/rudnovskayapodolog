# Работы Ольги

Продолжение существующего кабинета, отдельный Cloudflare Worker. Pages CMS для работы не нужен.

На этом этапе: список локальных работ, создание и редактирование пары, выбор из галереи, замена одного фото, обмен местами, IndexedDB с автосохранением и восстановлением после перезагрузки. JPEG/PNG и другие форматы, которые способен декодировать браузер; фото уменьшаются до 1200 px. При ошибке чтения старое фото сохраняется.

Это интерфейс черновиков: записи хранятся только в браузере на устройстве, не синхронизируются, не являются резервной копией и не отправляются на сайт. Существующие публичные работы доступны по ссылке «Посмотреть на сайте»; их импорт и серверное редактирование пока не подключены. Старый endpoint /publish удалён на этом этапе, чтобы исключить случайную отправку тестовых фото.

Запуск отдельного кабинета: из _cabinet выполнить `npx wrangler secret put ADMIN_PASSWORD` (длинный ASCII пароль), затем `npx wrangler deploy`. GITHUB_TOKEN для этого этапа не нужен. Логин olga. iPhone: открыть HTTPS адрес в Safari → Поделиться → На экран Домой. Манифест и иконка обслуживаются Worker.

Проверка: на ширинах 390 и 375 px добавить название и два тестовых JPEG, поменять местами, заменить только «До», вернуться к списку, перезагрузить и открыть работу. Проверить неполную пару и неподдерживаемый файл: введённые данные должны остаться. Тестовые фото не добавлять в репозиторий или публичную галерею.

В среде разработки прошёл node --check worker.mjs. Браузерная проверка заблокирована инфраструктурой preview: relay could not open browser port 4173. Поэтому проверка iPhone ещё не подтверждена.
